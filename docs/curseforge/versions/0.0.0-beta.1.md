<h2>v0.0.0-beta.1 - First release</h2>

<p>Utility Nexus Fixes bundles small compatibility and log-noise patches for third-party mod interactions that otherwise crash or flood the server log.</p>

<h3>Added</h3>
<ul>
<li><strong>Iris / Sodium compat patch</strong>: fixes the <code>ClassNotFoundException: SodiumGameOptions$PerformanceSettings</code> crash caused by Iris 1.8.12's Sodium-compat mixin referencing a class that Sodium 0.8.13 renamed to <code>SodiumOptions</code>.</li>
<li><strong>Lenient entity CustomName parse</strong>: malformed <code>CustomName</code> NBT (e.g. an unquoted string written by a datapack <code>tick</code> function) now falls back to plain text instead of throwing <code>Failed to parse entity custom name</code> with a stack trace every tick.</li>
<li><strong>Configurable log filter</strong>: drops a small, config-controlled allow-list of benign stale-NBT lines &mdash; by default <code>Tried to load invalid item: 'Item must not be minecraft:air'</code>, <code>Tried to load invalid item: 'Unknown registry key ...'</code>, <code>Tried to load invalid fluid: ...</code> and <code>Ignoring unknown attribute 'forge:...'</code>. Configure it in <code>config/utility_nexus/fixes/config.toml</code> under <code>[logfilter]</code>.</li>
</ul>

<blockquote>
All patches are no-ops when the mod they target is absent. Nothing is bundled and nothing is a hard dependency.
</blockquote>
