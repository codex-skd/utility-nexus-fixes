<h2>v1.0.0 - First stable release (Minecraft 1.21.1)</h2>

<p>First stable release of Utility Nexus Fixes for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong>
(Java 21). Same code as the internal <code>0.0.0-beta.3</code>; promoted to stable after running in
a full modded-server pack. It is a compatibility-patch mod &mdash; it fixes crashes and broken
interactions between third-party mods and adds no gameplay content.</p>

<h3>Patches</h3>
<ul>
<li><strong>Iris / Sodium compat</strong>: fixes the
<code>ClassNotFoundException: SodiumGameOptions$PerformanceSettings</code> /
<code>MixinTransformerError</code> crash caused by Iris 1.8.12's Sodium-compat mixin referencing a
class newer Sodium builds (0.8.13+) renamed.</li>
<li><strong>Lenient entity <code>CustomName</code> parse</strong>: malformed <code>CustomName</code>
JSON in stale NBT falls back to a plain-text component instead of throwing, stopping per-tick
<code>Failed to parse entity custom name</code> spam.</li>
<li><strong>Configurable Log4j2 filter</strong> (<code>BenignLogFilter</code>): drops a small,
config-controlled allow-list of benign stale-NBT / legacy-attribute log lines
(<code>[logfilter]</code> in <code>config/utility_nexus/fixes/config.toml</code>). Falls back to
the built-in defaults until the config is loaded, so it cannot crash mod loading.</li>
<li><strong>Nether return-portal fix</strong>: records, per entity, which exit portal was paired
with the portal you entered on an Overworld&harr;Nether trip and reuses it on the return trip
instead of vanilla's "closest portal" search. Toggle
<code>[fixes] enableNetherReturnPortalFix</code> (default <code>true</code>); mappings are
in-memory only and reset on restart.</li>
</ul>

<h3>Notes</h3>
<blockquote>No code change relative to <code>0.0.0-beta.3</code>. Verified:
<code>./gradlew clean build</code> is green.</blockquote>
