<h2>v1.1.0 - Better Villager Animations dialogue translation patch</h2>

<p>Adds a new optional, client-side compatibility patch for
<strong>Better Villager Animations</strong>. Same compatibility-patch philosophy as the rest of
this mod: it never touches the affected mod's jar, and the patch only activates when that mod is
present.</p>

<h3>Added</h3>
<ul>
<li><strong>Better Villager Animations dialogue translation</strong>: that mod keeps its villager
speech-bubble flavor text (greetings, small talk, trade banter &mdash; hundreds of lines) as
hardcoded Java string literals, so a normal <code>lang</code> resource pack cannot translate any of
it. Two soft, client-only mixins (<code>BvaDialogueMixin</code>, <code>BvaConversationMixin</code>,
gated by <code>BvaMixinPlugin</code> on <code>bettervillageranimations</code> actually being
loaded) intercept every internal <code>String.replace(...)</code> call the mod uses to substitute
its own placeholder tokens (player name, profession, workstation, time of day, weather&hellip;)
and translate the raw English line first, so the substitution then proceeds normally on the
Spanish text. A separately installed resource pack supplies the translation table at
<code>assets/bettervillageranimations/dialogue/es_es.json</code>; without that resource pack (or on
any other client language) the original English text is shown, unchanged.</li>
</ul>

<h3>Notes</h3>
<blockquote>Optional dependency on <code>bettervillageranimations</code> (client side only). No new
compile-time dependency was added to build this mod: the target classes are referenced by name
only (<code>@Pseudo</code> soft mixin target), never on the compile classpath. Verified:
<code>./gradlew clean build</code> is green.</blockquote>
